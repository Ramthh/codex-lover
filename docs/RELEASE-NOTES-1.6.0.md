# Codex Lover 1.6.0

- Free membership supports two saved Codex accounts with no time limit.
- Pro supports unlimited saved accounts for $9.99 USD per month, with PayPal automatic renewal managed on the website. Existing paid-through dates are honoured.
- Share feedback directly from the widget; messages arrive in the admin inbox.
- A small colored circle and Update button appear when the administrator publishes a newer available release. Clicking opens its Codex Lover release page.
- Codex resets shows today and the previous 29 days in UTC. Grey circles are unmarked; mint circles are dates published by the administrator. These are shared notices, separate from each account's quota reset time.
- Public update information refreshes every two minutes while the app is running.

Validation: 338 desktop tests passed before the final feedback color and footer spacing adjustments; final packaging rebuilds the app. Synthetic UI previews are under the desktop validation folder.
