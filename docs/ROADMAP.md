# Roadmap

This is a list of proposed work, not a promise of completion dates.

1. Collect clean-machine build and compatibility reports for the public source snapshot.
2. Improve keyboard and screen-reader documentation and address verified accessibility defects.
3. Expand tests for protocol changes, unavailable usage data and recovery edge cases.
4. Document a reproducible signed desktop release tied to a public source commit.
5. Explore a configurable/self-hosted membership service without weakening endpoint validation.

Contributors can start with documentation corrections, synthetic compatibility
fixtures, localization planning and focused bug reports. Real community use,
maintainer review and useful releases matter more than promotional metrics.
